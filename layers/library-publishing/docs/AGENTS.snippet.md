The npm package's public API is `src/lib/index.ts`; `src/index.ts` stays the app entry and isn't published. `npm run build:lib` builds `lib/` (ESM, CommonJS and types) with tsup, and `npm pack` / `npm publish` build it first. `npm run check:package` packs the package and checks with attw that the exports map resolves for import and require; CI runs it with the other checks. The `publish.yml` workflow runs every CI check, then publishes on a `v*` tag. Before the first tag, configure npm trusted publishing for the package on npmjs.com: this repository, workflow `publish.yml`, environment `npm`. The workflow publishes with provenance, which needs a public repository matching `repository` in package.json. `npm run publish:dry` shows what would be published.
