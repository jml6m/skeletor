The npm package's public API is `src/lib/index.ts`; `src/index.ts` stays the app entry and isn't published. `npm run build:lib` builds `lib/` (ESM, CommonJS and types) with tsup, and `npm pack` / `npm publish` build it first. Before a release, run `npm run publish:dry` (prepublishOnly: typecheck, lint, tests) and `npm run check:package` (attw: the exports map resolves for import and require). The `publish.yml` workflow runs the same checks and publishes on a `v*` tag.
