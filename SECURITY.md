# Security policy

## Supported versions

Security fixes go into the latest minor release of `@jml6m/skeletor`. Older versions are not
patched; upgrade to the latest release to get a fix.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through
[GitHub private vulnerability reporting](https://github.com/jml6m/skeletor/security/advisories/new).

Include the skeletor version, the `skeletor new` command (template and layers), and what an
attacker could do. Reports are handled on a best-effort basis; you'll get a reply in the advisory
thread, and a fix ships as a new release.
